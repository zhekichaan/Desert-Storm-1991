# Desert-Storm-1991
A 2D top-down tactical action game built in Unity. Navigate urban landscapes and combat, complete missions, manage resources, and engage in strategic combat from a top-down perspective.

# Dev Dependencies
- Unity Hub

- Visual Studio Code 2022

# Git Workflow (important)
1. Before starting new work, make sure your local main is up to date: **git pull origin main**
2. Create a branch for the feature or bug you’re working on. **git checkout -b feature/new-enemy-ai**
3. Work on Your Branch: **git add .git commit -m "Implement basic enemy AI movement"**
4. Push Your Branch to GitHub. **git push origin feature/new-enemy-ai**
5. Open a Pull Request (PR). Go to the repo on GitHub. Click Compare & pull request on your branch. Choose main as the target branch. Write a short description of your changes. Submit the PR for review.
6. Review and Merge. Team members review the PR. Once approved, merge into main using GitHub’s Merge Pull Request button. Delete the branch after merging to keep the repo clean, or keep it if the feature is important to document.
